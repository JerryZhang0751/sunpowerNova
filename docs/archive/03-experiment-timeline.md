## 读图要点

- **W1 是单点关键路径**（红色）：M0–M4 开发须在 ~8/1 前完成，才能在 8/2 采基线；而 M0 冒烟卡在 4 个 API key。**今天 7/27 已是 W1 第一天，key 仍是空的 → 基线有滑期风险。**
